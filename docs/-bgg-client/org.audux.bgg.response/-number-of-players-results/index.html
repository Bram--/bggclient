NumberOfPlayersResults

@Serializable
data class NumberOfPlayersResults(val numberOfPlayers: String, val results: List<PollResult>)(source)

Suggested number of players for associated thing. These results are 2-dimensional meaning each 'results' contains three singular results.

The XML looks as follows (Repeated for each numplayer possibility):

<results numplayers="1">
    <result value="Best" numvotes="0"/>
    <result value="Recommended" numvotes="0"/>
    <result value="Not Recommended" numvotes="2"/>
</results>
